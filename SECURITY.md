# Security policy

## Reporting a vulnerability

If you discover a security issue in this repository, please do not publish exploit details, secrets, personal information, or a working attack against a real target in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. Otherwise, contact the maintainer through the contact information on the GitHub profile and provide only the minimum details needed to reproduce the issue safely.

## Scope

This repository contains educational examples. The local HTTP demo is intended to bind only to loopback, and the payment-risk demo uses synthetic data. Please report unexpected behavior that could undermine these safety boundaries.

## Do not include

- Passwords, API keys, access tokens, or session cookies.
- Full payment-card numbers, CVV/CVC, track data, or real payment dumps.
- Third-party data collected without permission.
